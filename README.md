# Phishing Awareness & Social Engineering Training Module

## 📌 Project Overview
This repository contains the training materials, presentation slide deck, and knowledge evaluation modules engineered for **Task 2: Phishing Awareness Training** as part of the **CodeAlpha Cybersecurity Internship Program**.

The objective of this project is to educate corporate workforce personnel on identifying social engineering tactics, recognizing fraudulent emails/websites, and adhering to incident response protocols.

---

## 🛠️ Repository Contents
* `CodeAlpha_Phishing_Awareness_Training.docx`: Comprehensive training manual, threat analysis, case studies, and quiz module.
* `CodeAlpha_Phishing_Awareness_Presentation.pptx`: 7-slide interactive training presentation for security awareness sessions.
* `README.md`: Project documentation and submission details.

---

## 🧠 Key Modules Covered

### 1. Social Engineering Tactics & Psychology
* **Urgency & Fear:** Exploiting artificial deadlines to bypass critical thinking.
* **Authority Impersonation:** Posing as C-level executives or IT administrators.
* **Curiosity & Greed:** Using fake bonuses or gift cards as bait.

### 2. Technical Red Flags & Detection
* **Sender Domain Analysis:** Identifying header mismatches and spoofed domains.
* **Typosquatting & Subdomains:** Spotting fake root domains (e.g., `micros0ft.com`).
* **HTTPS Misconceptions:** Understanding why SSL padlocks do not guarantee site legitimacy.

### 3. Incident Response Protocol
* **Stop & Think:** Resisting emotional manipulation.
* **Out-of-Band Verification:** Confirming requests via known, official channels.
* **SOC Escalation:** Reporting suspicious messages to internal security teams.
